# Roxan S. Sindingan — Education 304 Digital Portfolio

A responsive static portfolio website based on the uploaded Education 304 Digital Learning Portfolio.

## Deploy to Vercel

### Option 1 — GitHub
1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js`.
3. In Vercel, choose **Add New Project** and import the repository.
4. Framework Preset: **Other**.
5. Build Command: leave blank.
6. Output Directory: leave blank / root.
7. Deploy.

### Option 2 — Vercel CLI
Install Vercel CLI, log in, then run `vercel` inside this folder.

This is a static site, so it does not require Laravel, PHP, Docker, or a database.
